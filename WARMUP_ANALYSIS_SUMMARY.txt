The warmup feature has ONE CRITICAL BUG that completely breaks it:

CRITICAL BUG #1: saveTestSegments() in sheets-helper.js (lines 278-287)
-----------------------------------------------------------------------
When admins save warmup segments WITHOUT an instructions URL, the segments 
array is EMPTY. The forEach loop never executes, so NO ROWS are added to 
Google Sheets. The warmup segments are completely lost.

IMPACT: 
- Admin saves 6 warmup segments
- Student logs in
- Sees "Warmup not configured" alert
- Cannot access warmup feature
- 100% FAILURE RATE for warmup-only configuration

================================================================================
HOW THE BUG MANIFESTS
================================================================================

SCENARIO:
1. Admin navigates to "Universal Settings"
2. Admin enters NO instructions URL (just warmup)
3. Admin splits warmup audio into 6 segments
4. Admin clicks "Save Universal Settings"

WHAT HAPPENS (WITH BUG):
1. Admin panel: testSegments[0] is empty, so segments = [] 
2. JavaScript sends: {testName: '_UNIVERSAL_INSTRUCTIONS', segments: [], warmupSegments: [url1...url6]}
3. API validates warmup URLs ✓
4. API calls: saveTestSegments(testName, [], '', '', [url1...url6])
5. saveTestSegments line 278: segments.forEach() - BUT SEGMENTS IS EMPTY!
6. forEach NEVER EXECUTES (cannot iterate over empty array)
7. filteredRows NEVER GETS UPDATED with warmup data
8. Google Sheets UPDATE writes old data (no new row created)
9. Warmup segments are LOST

STUDENT EXPERIENCE (RESULT):
1. Student logs in
2. Browser fetches _UNIVERSAL_INSTRUCTIONS config
3. getTestConfig() finds NO ROW (because it was never saved)
4. Returns: {warmupSegments: []} (empty)
5. Client logs: "No warmup found in universal config!"
6. testConfig.warmupSegments is NEVER POPULATED
7. Student clicks "Start Warmup"
8. startWarmup() checks: testConfig?.warmupSegments?.length > 0 = FALSE
9. Alert: "Warmup audio has not been configured"
10. No warmup feature available

================================================================================
ROOT CAUSE ANALYSIS
================================================================================

The function saveTestSegments() was designed with an implicit assumption:
"If you're saving to a test config, you must have at least one segment 
(either instructions URL or test segment URLs)."

This assumption BREAKS for the _UNIVERSAL_INSTRUCTIONS case where admin 
wants to save ONLY warmup segments with NO instructions.

CODE FLOW:
┌─────────────────────────────────────────────────────────┐
│ saveTestSegments(testName, segments, ..., warmupSegments)
├─────────────────────────────────────────────────────────┤
│ line 272: warmupValue = JSON.stringify(warmupSegments)  ✓
│ line 278: segments.forEach((url, index) => {            ✗ PROBLEM
│             filteredRows.push([...warmupValue...])      
│           })                                            
│ line 292: sheets.update(filteredRows)                   ✗ OLD DATA!
└─────────────────────────────────────────────────────────┘

If segments.length === 0:
- forEach NEVER EXECUTES
- filteredRows is UNCHANGED
- Google Sheets receives NO UPDATE
- Warmup is LOST

================================================================================
THE FIX (9 LINES)
================================================================================

FILE: /home/user/CIA/utils/sheets-helper.js
FUNCTION: saveTestSegments()
LINES: 278-287

BEFORE (BROKEN):
─────────────────────────────────────────────────────────
    // Add new segments
    segments.forEach((url, index) => {
      filteredRows.push([
        testName,
        (index + 1).toString(),
        url,
        'active',
        instructionsAudioUrl || '',
        warmupValue,
      ]);
    });

AFTER (FIXED):
─────────────────────────────────────────────────────────
    // Add new segments
    if (segments.length > 0) {
      segments.forEach((url, index) => {
        filteredRows.push([
          testName,
          (index + 1).toString(),
          url,
          'active',
          instructionsAudioUrl || '',
          warmupValue,
        ]);
      });
    } else if (warmupSegments.length > 0) {
      // If there are only warmup segments with no test/instruction segments,
      // still create a row to store them in the database
      filteredRows.push([
        testName,
        '1',
        instructionsAudioUrl || '',
        'active',
        '',
        warmupValue,
      ]);
    }

WHY THIS WORKS:
1. If segments.length > 0: Use original code (normal case)
2. If segments.length === 0 AND warmupSegments.length > 0: Create ONE row
   with warmup JSON in column F
3. getTestConfig() will find this row and extract warmup segments
4. Student will get warmup segments in testConfig
5. Warmup feature will work
